Reconstructing a Windows endpoint compromise

A single Windows host raised an alert, and no memory capture was available. Working only from event logs, the registry and file system artefacts, the job is to rebuild exactly what the attacker did, step by step.

Scenario

The EDR flagged a suspicious PowerShell command on a finance workstation. The host was isolated and a triage collection of its key artefacts was taken. There was no memory image, so every answer has to come from what Windows wrote to disk.

Questions to answer:

  • How did the attacker first get code running on the host?
  • What did they run, and in what order?
  • How did they try to keep access?
  • Did they cover their tracks?

Method

1. Triage the event logs for known attacker behaviour

$ hayabusa.exe csv-timeline -d C:\evidence\Logs -o hayabusa.csv
# Sigma-based rules highlight encoded PowerShell, new services and log clearing

Hayabusa gives a fast first pass, ranking hits by severity so the critical events stand out.

2. Decode what PowerShell actually ran

$ EvtxECmd.exe -f "Microsoft-Windows-PowerShell%4Operational.evtx" --csv C:\out
# Event 4104 (script block logging) records the decoded script

Script block logging shows the real command behind the Base64 blob: a download cradle fetching a second-stage payload.

3. Prove what executed, and when

$ PECmd.exe -d C:\evidence\Prefetch --csv C:\out
$ MFTECmd.exe -f C:\evidence\$MFT --csv C:\out

Prefetch confirms the payload ran and how many times; the $MFT shows when it was written to disk.

4. Find persistence and clean-up

$ RECmd.exe -d C:\evidence\Registry --bn BatchExamples\Kroll_Batch.reb --csv C:\out
# Then open everything in Timeline Explorer and sort by time

A scheduled task and a Run key both point at the payload. A cleared Security log (event 1102) shows the attacker tried to hide.

Lessons

  • Turn on PowerShell script block logging everywhere; it decoded the attacker's command when nothing else could.
  • Forward logs off the host in real time, so clearing them locally doesn't erase the evidence.
  • Prefetch and the $MFT can prove execution and timing even without a memory image.
  • Block Office and email clients from launching PowerShell.
